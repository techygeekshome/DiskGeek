# Getting DiskGeek's source code onto GitHub — what's left for you

I've created the private repository for you: **https://github.com/techygeekshome/DiskGeek**
(private — only you and anyone you invite can see it).

I can't push to it myself — pushing needs your Git credentials, which I don't handle
(same rule as Chocolatey: I prepare, you run the commands that actually authenticate).
The good news is if you've ever cloned or pushed to GitHub from this PC before, Windows
already has your credentials cached (via Git Credential Manager), so this should just
work without you having to paste a password or token anywhere.

## What I've put in this folder

- `.gitignore` — tells git to skip `bin/`, `obj/`, `publish/`, `installer/Output/`, and
  the built `DiskGeekSetup.exe` itself. Those are all regenerated by building the
  project, so they don't belong in source control (and `DiskGeekSetup.exe` alone is
  ~32MB, which would bloat the repo for no reason).
- `README.md` — a short description of the project and build instructions, so the repo
  isn't just a bare pile of code if you look at it in six months.

## What you need to do (4 commands, from this folder)

Open PowerShell, `cd` into `C:\Users\Tony Reilly\OneDrive\TGH\Programs\DiskGeek`, then:

```powershell
git init
git add .
git commit -m "Initial commit: DiskGeek source"
git branch -M main
git remote add origin https://github.com/techygeekshome/DiskGeek.git
git push -u origin main
```

If a browser window or credential prompt pops up asking you to sign in to GitHub, that's
normal — just approve it with your usual GitHub login. If you're already signed in on
this machine you likely won't see anything at all and it'll just push straight away.

That's it — after that, DiskGeek's source (both `DiskGeek.Core` and `DiskGeek.App`, the
installer script, and icons) will be versioned on GitHub, privately, under your account.

## If it complains about anything

Most likely cause would be it asking for a username/password in the terminal itself
(old-style, not a popup) — if you see that rather than a browser/graphical prompt, stop
and let me know rather than typing anything, since that usually means credential manager
isn't set up and there's a better way to sort it (a personal access token) that I'd
rather walk you through than have you paste blind.
